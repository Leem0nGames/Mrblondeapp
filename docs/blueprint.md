# **App Name**: Blonde Orders

## Core Features:

- Link Generation: Admin users can generate unique, temporary access links with customizable client types and agreement settings. The generated link directs clients to their pre-configured order form.
- Dynamic Pricing: The application automatically calculates product prices, factoring in client-specific markups, discounts, and active promotions. Prices are calculated in the backend using pricing rules and promotion eligibility to determine the final cost for each client type.
- Order Preview and Formatting: Presents a clear breakdown of the client's order, inclusive of quantity, per-item price, and all associated discounts and/or promotions. Clients can then send this summary to the company via a pre-formatted WhatsApp message.
- Product Catalog Management: An admin interface that simplifies adding new products and editing existing product attributes, allowing for immediate pricing updates, stock adjustments, and promotional adjustments.  Leverages a table format that is simple to browse and edit.
- Client Segmentation and Agreements: Admin users can define different client types, creating agreement terms tailored to individual clients or client segments, as well as overriding standard pricing or promotions, supporting bespoke deals for preferred distributors or customers.
- Smart Order Tool: Leverage an AI tool to intelligently assess and automatically apply the most advantageous promotions or bundled offers based on a user’s cart items and quantities, with an explanation provided for why it's being recommended to the end user. Use a generative AI tool to choose whether or not each offer makes sense, in turn increasing revenue.

## Style Guidelines:

- Primary color: Muted yellowish-beige (#E4D5B7), reminiscent of desert sands, creating a natural, grounded feel.
- Background color: Very light beige (#F7F4F0), almost white, maintaining a clean and uncluttered interface.
- Accent color: Deep brown (#4A3A2A), evoking a sense of sophistication and quality, providing a strong contrast against the lighter palette.
- Headline font: 'Belleza' sans-serif, adding a touch of personality suitable for art, fashion and design.
- Body font: 'Alegreya' serif, to maintain readability, warmth, and an elegant, intellectual feel.
- Code font: 'Source Code Pro' monospace, when displaying code snippets.
- Use of line icons from Lucide React. Keep the styling simple, monochrome and clean.
